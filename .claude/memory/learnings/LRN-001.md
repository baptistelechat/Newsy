# LRN-001 — Suivre un repo GitHub = ajouter son releases.atom à defaultFeeds

**Pattern observé** : Pour suivre les releases d'un projet GitHub, l'URL `https://github.com/<owner>/<repo>/releases.atom` ajoutée à `defaultFeeds` dans `src/config.ts` suffit — `rss-parser` l'interprète comme n'importe quel autre flux RSS, sans code supplémentaire ni parsing dédié.

**Contexte** : Ajout successif des flux pyRevit (`pyrevitlabs/pyRevit`), PowerToys (`microsoft/PowerToys`) et Uptime Kuma (`louislam/uptime-kuma`) — même format d'URL à chaque fois, aucune adaptation nécessaire côté code.

**Application future** : Pour tout nouveau repo GitHub à surveiller, ajouter simplement son URL `releases.atom` à `defaultFeeds` (+ une ligne `### Added` dans `CHANGELOG.md`) — jamais besoin d'écrire un parseur spécifique.
