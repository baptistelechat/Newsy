# BDR-002 — Persistance sur fichiers JSON locaux plutôt qu'une base de données

**Décision** : Les abonnés (`subscribers.json`) et les articles déjà envoyés (`sent.json`) sont stockés dans des fichiers JSON sur disque, gitignorés, plutôt que dans une base de données.

**Pourquoi** : Le bot est volontairement léger et auto-hébergeable (single process Node.js, aucune dépendance externe à provisionner) ; le volume de données (une liste de `chat_id` et des identifiants d'articles déjà vus) reste trivial pour un fichier JSON.

**Alternatives considérées** : SQLite ou une base distante (Postgres/Supabase) — écartées pour garder un déploiement "zéro infra" (juste `git pull` + `pnpm build` + redémarrage PM2).
