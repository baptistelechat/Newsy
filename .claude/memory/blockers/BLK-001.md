# BLK-001 — Un flux RSS cassé bloquait silencieusement tous les envois

**Friction** : Après un changement de format côté source (`hexabim.com/blog/rss`), le flux renvoyait du XML invalide. La boucle d'agrégation plantait dès ce flux, bloquant les crons quotidien et hebdomadaire sans aucun log explicite désignant la source fautive — plus aucun article envoyé pendant plusieurs semaines, alors que les autres flux fonctionnaient très bien.

**Cause réelle** : Un seul `try/catch` global autour de la boucle sur `APP_CONFIG.defaultFeeds`, sans isolation par itération — une exception sur une source remontait et coupait le traitement des sources suivantes.

**Solution** : Wrapper chaque appel `rss-parser.parseURL()` dans son propre `try/catch` (log + `continue` implicite) dans `daily.cron.ts`, `weekly.cron.ts` et `bot.ts` (`/latest`) — commit `ed17ee5`.
